## 🤝 Tham gia đóng góp

Chào mừng mọi đóng góp! Quy trình chuẩn:

```bash
# 1. Fork repo này
# 2. Tạo branch mới
git checkout -b feat/ten-tinh-nang

# 3. Thực hiện thay đổi, commit theo Conventional Commits
git commit -m "feat(scope): mô tả ngắn gọn"

# 4. Push lên fork của bạn
git push origin feat/ten-tinh-nang

# 5. Mở Pull Request → nhánh main
```
